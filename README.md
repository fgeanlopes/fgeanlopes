### Featured project

**[Night Home for Chromecast with Google TV](https://github.com/fgeanlopes/chromecast-night-home)**: an ad-free home screen designed for a dark bedroom and low vision. Three card styles and backgrounds switched live from the TV remote, app icons automatically reduced to one-color drawings of the same size, and the current weather without an API key. Java, built on [cleanyourtv](https://github.com/Gathin23/cleanyourtv), with 215 unit tests.

### Building with AI

AI changed how much one developer can build. I use it on purpose to ship more and spend less time on boilerplate and details, and put my years of frontend experience where AI can't decide for me: product, UX and code review.

- **Spec and prototype first**, so the AI builds the right thing
- **Small, tested steps**, with the key decisions written down
- **Done means it works on the real device**: tests pass and screenshots prove it
